# Lumière Studio — Premium Beauty Salon Template

**DigiCheste** · Template Premium Beauty Salon v1.0  
Stack: Next.js 14 + TypeScript + Tailwind + Framer Motion + GSAP + Lenis  
Locales: ES / EN · Deploy: Vercel + Railway

---

## Quick Start

```bash
# Install frontend deps
cd lumiere-studio
npm install

# Run dev (frontend only)
npm run dev          # → http://localhost:3000

# Run backend (separate terminal)
cd server
npm install
npm run dev          # → http://localhost:3001
```

## Environment Variables

Copy `.env.example` and fill in values:

```bash
cp .env.example .env.local     # frontend
cp .env.example server/.env    # backend
```

Required for email:
- `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`
- `EMAIL_FROM`, `EMAIL_TO`

## Deploy

### Frontend → Vercel

1. Import the `lumiere-studio` directory into Vercel
2. Set environment variables in Vercel dashboard (see `vercel.json`)
3. Deploy — automatic

### Backend → Railway

1. Create a new Railway project pointed at `server/`
2. Railway auto-detects the `Dockerfile`
3. Set environment variables in Railway dashboard
4. Copy the Railway public URL → set as `NEXT_PUBLIC_API_URL` in Vercel

## White-Label Customisation (2–4h per client)

| Step | What to change | Where |
|------|---------------|-------|
| 1 | Salon name | `messages/es.json` + `messages/en.json` |
| 2 | Images | `public/images/` (Midjourney prompts in brief) |
| 3 | Address / hours / contact | Both message files + `components/ui/JsonLd.tsx` |
| 4 | Services & pricing | `server/data/services.json` |
| 5 | Email credentials | Server environment SMTP vars |
| 6 | Deploy | Vercel (frontend) + Railway (backend) |
